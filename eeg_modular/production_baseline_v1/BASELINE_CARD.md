# Production Baseline v1

## 冻结状态

| 项目 | 冻结值 |
|---|---|
| 状态 | 已训练并封存的正式部署模型 |
| 情绪分类输入 | `filtered + bandpower` |
| 输入形状 | 两个 `(10, 4)` 张量 |
| Accuracy | 63.88% |
| Macro-F1 | 62.69% |
| 验证方式 | 26 名受试者隔离，3 个随机种子 × 5 折 |

## 输入职责

- `filtered`：参与情绪类别预测。
- `bandpower`：参与情绪类别预测。
- `ATT`：不参与情绪分类，仅用于仪表盘、注意力趋势、辅助解释和反馈规则。
- `MED`：不参与情绪分类，仅用于仪表盘、状态解释和反馈规则。
- `Poor Signal`：只用于信号质量门控和拒识。

分类接口不得将 ATT/MED 拼接进模型输入。反馈决策可以在分类结果产生后独立读取 ATT/MED。

## 证据边界

完整四模态的 Accuracy 为 63.46%、Macro-F1 为 62.20%。受试者级比较 `E_all − D_filtered_bandpower` 的平均 Accuracy 差为 `-0.0006`，95% bootstrap CI 为 `[-0.0542, 0.0522]`，Wilcoxon `p=0.9636`。

正式表述为：

> 未观察到完整四模态优于纯 EEG 的证据。

不得将该结果表述为“两者完全相同”或“证明 ATT/MED 永远无效”。

## 模型资产说明

当前 `model.pt` 使用全部 277 个有效窗口、全部 26 名受试者，从随机种子 42 全新初始化并训练 20 epochs。两个 Scaler 分别使用全部训练窗口重新拟合。轮数来自15次分组交叉验证 `best_epoch` 的中位数；训练未读取实采结果调参，也未从任何折权重继续训练。

该权重称为“基于全部可用训练数据重新训练的部署模型，其性能引用严格分组交叉验证结果”。63.88% / 62.69% 是评估流程的聚合结果，不是该全量权重自身的独立测试成绩。

## 置信度与拒识

交叉拟合 Temperature Scaling 在277个窗口的三种子OOF集成分析上使 NLL、Brier Score 和 ECE 均恶化，因此不部署温度缩放。Softmax置信度只作为选择性预测分数，不解释为预测正确概率。

正式拒识阈值为 `0.60`。选择依据是在候选阈值0.40至0.65中，首个使三种子单模型OOF平均接受准确率达到70%的阈值：

- 覆盖率：47.41%
- 接受预测Accuracy：70.67%
- 接受预测Macro-F1：65.85%
- 三种子中最低接受Accuracy：67.55%

该阈值仍需在真实MindWave试测中持续记录覆盖率；不得因单次实采拒识率高而直接降低。
