# 60–90秒无监督个人基线校准 v1

## 产品流程

1. 用户正确佩戴MindWave，睡眼放松采集90秒。
2. 前30秒只用于填充模型窗口，之后每2秒生成一窗，约得到31个候选窗。
3. 先执行Quality Gate v1。可信窗口少于80%或有效窗少于16个时，不拟合校准参数，提示重新佩戴。
4. 仅对生产Scaler后的`filtered + bandpower`fit个人中位数偏移，不使用情绪标签。
5. 每个特征维度最大只校正3个标准差，防止异常基线大幅扭曲输入。
6. 校准后仍必须通过原始信号质量门；校准不得屏蔽伪迹或Poor Signal。

## 评估边界

- 该方法不使用标签，适合首次佩戴初始化。
- 当前277窗训练集没有每名受试者独立的60–90秒静息基线，因此不得使用测试受试者全部数据模拟校准，也不得宣称已获得交叉验证性能增益。
- 产品原型可展示该初始化流程，性能改善需在后续有专用基线数据的新用户实验中验证。
