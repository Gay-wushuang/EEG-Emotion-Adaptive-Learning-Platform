## 已恢复的训练特征契约

训练模型并不是从 `rawwave.csv` 在线生成全部模态，而是依赖采集软件提前生成的
`filtered.csv` 与 `powerspec.csv`：

1. 每个CSV只取 `Time` 之外的第一列。对 `powerspec.csv` 来说，这意味着只取
   512个频谱列中的首列（列名 `0`），其余频率列全部未参与训练。
2. 时间戳只有秒级精度。
3. 使用Pandas按100 ms重采样：`mean → linear interpolate → ffill → bfill`。
4. 只有filtered模态额外执行Butterworth带通：
   `low=0.5 Hz, high=45 Hz, fs=128 Hz, order=5, filtfilt`。
5. 长度为N的序列使用 `seg_len=N//10`，按十段切分；不能整除的尾部余数被丢弃。
6. 每段特征顺序严格为 `[mean, std, max, min]`。
7. 四个模态分别使用自己的StandardScaler。

黄金样本中，filtered源文件有15360点、标准差76.70；按100 ms重采样后仅291点、
标准差4.11；再次按训练带通后标准差4.60。幅度下降主要来自“100 ms分箱取均值”，
不是固定除以10。

## 部署偏离点

当前MindWave适配器：

- 直接对512 Hz Raw执行FFT带通，再把15360点分成10段；
- 没有复用训练用的预生成 `filtered.csv`；
- 自行计算宽带对数功率包络。

训练端：

- 对采集软件已经生成的filtered序列先做100 ms均值重采样；
- powerspec只使用预生成频谱的0 Hz首列；
- 没有保存生成 `filtered.csv` 和 `powerspec.csv` 的上游算法或版本。

因此，现有代码能精确复现“CSV到模型张量”，但无法从Raw EEG精确复现这两个上游CSV。
旧模型的完整 Raw-to-model 特征契约仍不完整。

## 决策

不应对实时filtered手动除以10，也不应继续用旧模型开展任务实验。

若无法找到生成训练 `filtered.csv` 和 `powerspec.csv` 的原采集软件算法与参数，
应确定唯一的Raw-to-feature实现，重新处理405段数据、拟合scaler并重新训练。
训练、离线验证与实时部署必须导入同一个特征提取模块。
